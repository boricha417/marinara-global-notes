# 글로벌 노트 1.4.5 (Marinara Engine 확장)

Marinara Engine 개인 확장입니다. (2.5.0 ~ 2.5.1 호환 확인, 2.4.x는 1.3.x 때의 툴바 방식으로 동작) 여러 채팅방에서 다시 쓰는 **유저 노트**를 한곳에 모아 두고, 방마다 원하는 노트만 골라 연결합니다. 엔진은 건드리지 않고 순정 마리나라의 **로어북** 시스템만 사용합니다. 작가노트처럼 방마다 따로 적던 "내 캐릭터 설정", "문체 지시", "자주 쓰는 상황 메모"를 한 번만 적어 두고 체크로 꺼내 쓰는 용도입니다.

## 들어가는 자리

- **2.5.0 이상** — 채팅 화면의 **채팅 설정(슬라이더) 버블 옆**에 같은 모양의 버블이 하나 더 생깁니다. 앱 버블처럼 **끌어서 옮길 수 있고**, 놓은 자리는 **방마다** 기억됩니다(PC·폰 따로). 채팅 설정 버블 위에 놓으면 저장된 자리를 지우고 자동 자리로 돌아갑니다. 설정 버블을 옮기면 자동 자리의 노트 버블도 따라갑니다.
- **2.4.x 버전** — 채팅 설정 버블이 없으면 자동으로 이 방식으로 바뀝니다. 채팅 툴바의 **작가노트 버튼 옆**에 버튼이 들어가고, 모바일에서는 점 세 개 메뉴 안에 들어갑니다.
- 버블·버튼에는 알림 점이나 음영 같은 **활성 표시를 넣지 않았습니다.** 기본 버블과 똑같이 보이도록 일부러 뺀 것입니다. 연결된 노트 수는 패널을 열면 제목 아래에 보입니다.

## 패널

버블을 누르면 노트 패널이 열립니다. 채팅방을 열지 않은 상태에서는 "채팅방을 열면 노트를 연결할 수 있어요"만 보이고, 체크는 할 수 없습니다.

| 영역 | 설명 |
| --- | --- |
| 체크박스 | 체크하면 **이 방에** 연결됩니다. 다른 방에는 영향이 없습니다. |
| 노트 이름 줄 | 누르면 아코디언으로 펼쳐져 바로 편집할 수 있습니다. 여러 개를 동시에 펼쳐 비교할 수 있습니다. |
| 여섯 점 손잡이 | 드래그해서 순서를 바꿉니다. 순서는 서버에 저장됩니다. 검색 중에는 바꿀 수 없습니다. |
| 돋보기 | 이름이나 내용으로 검색합니다. |
| 새 노트 | 패널 아래 고정 바에 있어 목록이 길어도 항상 보입니다. 작성 중에는 목록이 "노트 N개 접힘" 한 줄로 접힙니다. |
| 편집기 펼치기 | 내용 칸을 큰 창으로 띄워 적습니다. 본문과 실시간으로 같은 내용입니다. |
| 삭제 | 노트를 지우면 **모든 채팅방에서** 사라집니다. 확인 창이 한 번 뜹니다. |

## 노트 한 개의 설정

| 항목 | 설명 |
| --- | --- |
| 노트 이름 / 내용 | 내용 칸 옆에 대략의 토큰 수가 표시됩니다(추정치). |
| 항상 / 조건부 (키워드) | **항상**은 연결된 방에서 매번 주입됩니다. **조건부**는 적어 둔 키워드가 최근 대화에 나타날 때만 주입됩니다. 키워드는 쉼표나 줄바꿈으로 여러 개 적습니다. |
| 주입 깊이 | 0이면 마지막 메시지 뒤, 기본은 4입니다. 로어북 엔트리의 At Depth와 같습니다. |

## 어떻게 저장되나

- 처음 쓸 때 **"🗒️ 글로벌 노트"**라는 로어북을 자동으로 만듭니다. 노트 하나가 엔트리 하나입니다. 이 로어북의 이름을 바꾸거나 지우면 확장이 새 로어북을 만들므로, 로어북 메뉴에서 직접 손대지 않는 것이 좋습니다.
- "이 방에 연결"은 그 방의 활성 로어북 목록에 이 로어북을 넣고, 연결하지 않은 노트는 그 방에서만 끄는 방식입니다. 순정 로어북은 방 단위로 엔트리를 **끄는 것만** 할 수 있어서, 새 노트를 만들면 이 로어북을 쓰는 다른 방 전체에 "끄기"를 먼저 적어 둡니다. 그래서 새 노트가 다른 방에 몰래 들어가는 일은 없습니다.
- 노트 본문·순서·연결 상태는 전부 서버(로어북·방 메타데이터)에 저장되어 어느 기기에서 열어도 같습니다. 버블 위치만 브라우저에 저장됩니다.

## 알아둘 점

- 로어북 주입이므로 **생성 시점에 프롬프트에 들어갑니다.** 패널에서 체크를 바꾼 뒤 다음 메시지부터 반영됩니다.
- 로어북의 스캔 깊이는 5, 토큰 예산은 8192로 만들어집니다. 노트가 아주 많거나 길면 예산을 넘는 노트는 잘릴 수 있습니다.
- 다른 기기나 탭에서 같은 방의 연결을 바꾸면, 이 탭은 패널을 다시 열 때 최신 상태를 읽습니다.
- 모바일에서 입력 칸을 누르면 패널이 키보드 위로 접히고, 누른 칸이 보이도록 스크롤됩니다. 이름 칸은 삼성 키보드의 자동완성 바를 피하려고 한 줄짜리 textarea로 되어 있습니다.
- 활성 방 감지는 마리나라가 브라우저 저장소에 적는 현재 방 ID를 0.8초마다 읽는 방식입니다.

## 확장이 기대는 화면 표식

- 2.5.0+ 버블: `[data-chat-settings-button]`, `.mari-window-bubble`
- 2.4.x 툴바: `button[aria-label="작가노트"]` / `"Author's Notes"`, 오버플로 메뉴 `[data-chat-toolbar-overflow-menu]`
- 앱의 메뉴 닫힘 예외: 패널에 `data-chat-floating-panel`을 붙여 패널 안 클릭이 바깥 클릭으로 오인되지 않게 합니다.
- 활성 방: `localStorage["marinara-active-chat-id"]`
- API: `/api/lorebooks`(로어북·엔트리·순서), `/api/chats/:id`(활성 로어북 목록·엔트리 오버라이드). 쓰기 요청에는 `x-marinara-csrf: 1` 헤더를 붙입니다.

엔진이 이 구조를 바꾸면 해당 자리만 손보면 됩니다.

## 설치

1. **설정 → 고급 → 위험 구역**에서 "외부 확장 가져오기 허용"을 켭니다.
2. **설정 → 애드온 → 외부 확장**에서 이 저장소의 zip 또는 폴더(`manifest.json`, `extension.js`, `extension.css`)를 가져옵니다. GitHub 확장 관리자 확장을 쓰면 저장소 주소를 등록해 업데이트도 받을 수 있습니다.
3. 가져온 확장은 꺼진 상태로 들어옵니다. 코드 해시를 확인하고 **승인 → 활성화**합니다. 코드가 바뀔 때마다 다시 승인해야 합니다.

이 확장은 `marinara.extension` 종류로, 마리나라 페이지 안에서 그대로 실행됩니다(full page access). 페이지에 보이는 것을 읽고 바꿀 수 있는 권한이므로 코드를 확인한 뒤 승인하세요.

## 버전 이력
